## Visit the website

[**littlepaintandwonder.github.io →**](https://littlepaintandwonder.github.io/)

## About

Little Paint & Wonder creates colourful creative craft activities for little hands and big imaginations, made with love in Australia.

This repository contains the ClojureScript application, styling, assets, and GitHub Pages deployment configuration used to build the live website.

## Built with

- ClojureScript
- Reagent
- shadow-cljs
- Custom CSS
- GitHub Actions + GitHub Pages

## Development

See [`src/README.md`](src/README.md) for local development, building, deployment, and project-structure notes.

## Deployment

Pushes to `main` trigger the GitHub Actions workflow, which builds the application and publishes `docs/` to GitHub Pages.
