# Little Paint & Wonder

**Live website:** https://littlepaintandwonder.github.io/

Little Paint & Wonder is a colourful creative-kit website built with ClojureScript and deployed to GitHub Pages.

## Visit the site

[**littlepaintandwonder.github.io →**](https://littlepaintandwonder.github.io/)

This repository contains the source code and deployment configuration for the website. The GitHub repository is the project behind the site; the public-facing destination is the live GitHub Pages website above.

## Built with

- ClojureScript
- Reagent
- shadow-cljs
- Custom CSS
- GitHub Actions + GitHub Pages

## Development

See [`src/README.md`](src/README.md) for local development, build, deployment and project-structure notes.

## Deployment

Pushes to `main` trigger the GitHub Actions deployment workflow and publish the production build to GitHub Pages.
